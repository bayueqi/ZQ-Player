FEATURES

功能

播放、曲库、流媒体与桌面集成，都在同一个客户端里。

扫码与手机号登录

扫码或手机号登录网易云账号，同步歌单、收藏与播放记录。

桌面歌词

独立歌词窗口，逐字滚动、双语翻译，支持全局快捷键。

主题色自适应

从封面提取主题色，着色整个界面，支持 Light / Dark / Auto。

本地曲库

导入本地歌曲，自动分类，支持标签与封面编辑。

云盘

上传音乐到云盘，直接播放，支持歌曲纠正与删除。

Subsonic / Navidrome

接入自建流媒体服务，支持多服务器与自动连接。

MV 与视频

支持 MV 与视频播放。

频谱与淡入淡出

实时显示音乐频谱，支持音乐渐入渐出。

离线播放

切换为本地播放器模式后完全不连接网络，适合离线使用。

PWA

网页版支持安装到桌面与手机主屏，移动端基础适配。

深色模式

跟随系统自动切换浅色与深色外观，也可手动指定。

Last.fm Scrobble

把播放记录上报到 Last.fm。

部署

Docker 镜像包含网页端与运行所需服务；也可以从源码构建客户端。

Docker 
git clone https://github.com/bayueqi/zq-player.git
cd zq-player
docker build -t zq-player .
docker run -d --name zq-player -p 25884:25884 zq-player

访问 http://localhost:25884

本地部署 
pnpm install
pnpm dev
pnpm build:win   # build:mac / build:linux

打包输出在 dist 目录
